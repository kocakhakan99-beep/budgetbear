# budgetbear

BudgetBear is an offline-first personal budgeting web app for local use.

## App entrypoints
- `index.html` is the primary app entrypoint.
- `kodin_talousstudio_v1_1.html` redirects to `index.html` for backwards compatibility.

## Repository structure
- `index.html` — app shell markup
- `src/css/app.css` — extracted application styles
- `src/js/app.js` — extracted application logic
